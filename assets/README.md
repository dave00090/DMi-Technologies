# Android Assets

Please place your app icons and splash screens here.

Required files for `npx capacitor-assets`:
- `icon-only.png` (at least 1024x1024)
- `icon-foreground.png`
- `icon-background.png`
- `splash.png` (at least 2732x2732)
- `splash-dark.png` (optional)

After adding these files, run:
`npm run android:assets`
